# DaktRecorder

Запись звонков на macOS одной кнопкой: приложение пишет микрофон и системный
звук — голоса собеседников в Zoom, Meet, Telegram, браузере.

Виртуальные аудиодрайверы (BlackHole, Loopback) не нужны: системный звук
берётся через ScreenCaptureKit.

## Требования

- macOS 13 или новее
- Command Line Tools: `xcode-select --install`

Xcode-проект не нужен, сборка идёт напрямую через `swiftc`.

## Установка

```sh
git clone https://github.com/meloch287/dakt-recorder.git
cd dakt-recorder
./build.sh
open DaktRecorder.app
```

Скрипт собирает бандл `DaktRecorder.app`, рисует иконку и подписывает результат
ad-hoc — без подписи macOS может забыть выданные разрешения после очередной
сборки. Пересборка после правок — тот же `./build.sh`, приложение перед этим
лучше закрыть.

Бандл можно перетащить в `/Applications`. После переноса разрешения придётся
выдать заново: система привязывает их к расположению бандла.

## Разрешения

| Разрешение | Зачем | Где включить |
| --- | --- | --- |
| Микрофон | свой голос | запрос при старте записи |
| Запись экрана и системного звука | голоса собеседников | Системные настройки → Конфиденциальность и безопасность → Запись экрана |
| Распознавание речи | расшифровка, если включена | запрос при первой записи с расшифровкой |

После включения записи экрана приложение нужно перезапустить.

Проверка: если во время записи индикатор «Zoom / системный звук» не двигается,
второе разрешение не выдано.

## Управление

Кнопка в окне — старт и стоп. Во время записи рядом появляется пауза: обе
дорожки замирают одновременно, и пауза не попадает в файл.

Значок в строке меню повторяет старт, стоп и паузу. Горячая клавиша ⌘⇧R
запускает и останавливает запись из любого приложения — окно держать открытым
не нужно.

## Настройки

Шестерёнка в правом верхнем углу окна:

| Раздел | Что настраивается |
| --- | --- |
| Микрофон | входное устройство, фильтр гула ниже 90 Гц, шумодав в паузах |
| Источник звука | вся система или только выбранное приложение |
| Сведение | выравнивание громкости дорожек по среднему уровню |
| Файлы | сжатие сырых дорожек, удаление после сведения, свободное место |
| Автостоп | остановка записи после N минут тишины |
| Расшифровка | текст с ролями после остановки, пять языков |
| Окно и клавиши | значок в строке меню, горячая клавиша |

Там же список незавершённых записей: если приложение закрыли аварийно и сырые
дорожки остались без сведения, кнопка «Собрать» доделает mix.

## Результат

`~/Documents/DaktRecorder/2026-08-17_14-30-12/`

| Файл | Содержимое |
| --- | --- |
| `mix.m4a` | обе дорожки в одном файле |
| `mic.caf` | только микрофон |
| `system.caf` | только собеседники |
| `transcript.txt` | расшифровка с ролями, если включена |

Отдельные дорожки нужны для расшифровки по ролям и для перемикширования, если
один голос тише другого. В несжатом виде они занимают около 35 МБ в минуту —
примерно 2 ГБ за час встречи; в настройках можно включить сжатие или удаление
после сведения.

В системную дорожку по умолчанию попадает всё, что звучит в системе: не только
собеседники, но и уведомления, музыка, видео в соседней вкладке. Чтобы этого не
было, выберите в настройках конкретное приложение.

## Расшифровка

`transcript.txt` — реплики с таймкодами, разделённые на «Я» и «Собеседник».
Распознавание идёт встроенными средствами macOS, скачивать модели не нужно.
Роли определяются не по голосу, а по дорожке, поэтому не путаются.

## Как это работает

- Микрофон — `AVAudioEngine`, тап на входном узле; при включённом фильтре
  сигнал идёт через `AVAudioUnitEQ`, выход микшера заглушен, эха нет.
- Системный звук — `SCStream` из ScreenCaptureKit, звук самого приложения
  исключён. Наушники не мешают: сигнал берётся до вывода на устройство.
- Обе дорожки приводятся к 48 кГц float32 и пишутся независимо.
- На стопе дорожки складываются в `mix.m4a` с выравниванием по времени первого
  сэмпла, так что задержка старта одного из источников не даёт рассинхрона.
  Пики выше 0.8 поджимаются мягким лимитером — одновременная речь не трещит.
- Выравнивание громкости считает RMS дорожки без учёта тишины; поправка
  ограничена четырёхкратной, чтобы шум не вытянулся.
- Если AAC-кодировщик недоступен, сведение пишется в `mix.wav` рядом.
- Выход из приложения во время записи не теряет её: macOS ждёт, пока файлы
  допишутся и дорожки сведутся.

## Структура

```
Sources/
  DaktRecorderApp.swift       точка входа, строка меню, завершение без потерь
  ContentView.swift           окно: кнопка, пауза, таймер, индикаторы уровня
  SettingsView.swift          настройки под шестерёнкой
  Preferences.swift           хранение настроек
  RecorderController.swift    состояние записи, автостоп, восстановление
  MicCapture.swift            микрофон, устройство, фильтр, шумодав
  SystemAudioCapture.swift    системный звук, фильтр по приложению
  AudioDevices.swift          список входов и переключение
  Mixdown.swift               сведение, лимитер, выравнивание громкости
  AudioSupport.swift          формат, запись в файл, конвертация
  Transcription.swift         расшифровка с ролями
  GlobalHotKey.swift          ⌘⇧R поверх всех приложений
Tools/
  MakeIcon.swift              рисует иконку при сборке
build.sh                      сборка бандла
Info.plist                    идентификатор, версия, описания разрешений
```

## Планы

- Настраиваемое сочетание клавиш вместо фиксированного ⌘⇧R
- Расшифровка через whisper.cpp как альтернатива встроенному распознавателю
- Разделение говорящих внутри системной дорожки, когда собеседников несколько
- Экспорт расшифровки в SRT и VTT
